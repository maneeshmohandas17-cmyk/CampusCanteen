How it works
  • New canteens you add here appear immediately in the student menu filter pills.
  • When adding a new food dish, you can assign it to any combination of canteens from the list.
  • Removing a canteen does not delete food items — it only disassociates them from that canteen.
  • Canteen staff can log in using the canteen name as both username and password (admin123 also works as password).
